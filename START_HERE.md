### ⚠️ ВАЖНО: Настройка переменных окружения

Перед запуском создайте файл `.env` с секретным ключом:

```bash
# Создайте .env файл
cat > .env << EOF
# Секретный ключ для JWT токенов (обязательно!)
SECRET_KEY=$(openssl rand -hex 32)

# Опционально: для автоматического создания первого пользователя
# Если не заполнено - используйте регистрацию через веб-интерфейс
PYRUS_LOGIN=
PYRUS_SECURITY_KEY=
EOF
```

**Примечание:** `PYRUS_LOGIN` и `PYRUS_SECURITY_KEY` теперь **опциональны**! 
Вы можете зарегистрироваться через веб-интерфейс после запуска приложения.

---

### Вариант A: Автоматическая установка (рекомендуется) ⭐

Выполните всего 2 команды:

```bash
# 1. Установка и настройка Nginx на хосте
sudo ./SETUP_COMMANDS.sh

# 2. Запуск приложения
./prod.sh up
```

**Готово!** Приложение будет доступно по адресу: `http://адрес_вашего_сервера/pyrus/`

---

### Вариант B: Ручная установка (если хотите понимать каждый шаг)

```bash
# Шаг 1: Установите Nginx
sudo apt update && sudo apt install -y nginx

# Шаг 2: Скопируйте конфигурацию
sudo cp nginx-host.conf /etc/nginx/sites-available/pyrus

# Шаг 3: Активируйте конфигурацию
sudo ln -s /etc/nginx/sites-available/pyrus /etc/nginx/sites-enabled/

# Шаг 4: Проверьте и перезапустите Nginx
sudo nginx -t
sudo systemctl restart nginx

# Шаг 5: Запустите приложение
./prod.sh up
```

## 🆘 Проблемы?

### Приложение не открывается

1. Проверьте статус контейнеров:
   ```bash
   ./prod.sh ps
   ```

2. Проверьте логи:
   ```bash
   ./prod.sh logs
   ```

3. Проверьте Nginx на хосте:
   ```bash
   sudo systemctl status nginx
   sudo nginx -t
   ```

### Порт 80 занят

Если порт 80 уже используется другим приложением, измените порт в файле `nginx-host.conf`:
```nginx
listen 8080;  # Вместо listen 80;
```

Затем откройте порт в firewall:
```bash
sudo ufw allow 8080/tcp
```

Приложение будет доступно по адресу: `http://адрес_сервера:8080/pyrus/`

---

## 🔒 Firewall (опционально)

Если на сервере включен firewall, откройте порт 80:

```bash
# Для всей сети
sudo ufw allow 80/tcp

# Или только для корпоративной сети (пример)
sudo ufw allow from 192.168.0.0/16 to any port 80 proto tcp
```
