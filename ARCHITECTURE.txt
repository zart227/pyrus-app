ВАЖНЫЕ ПОРТЫ:

  Порт 80    - Nginx на хосте (слушает запросы из сети)
  Порт 8082  - Docker Nginx (внутренний маршрутизатор)
  Порт 8000  - Backend API
  Порт 5433  - PostgreSQL (доступ с хоста)

═══════════════════════════════════════════════════════════════════════

ПУТЬ ЗАПРОСА:

  1. Клиент → http://server/pyrus/
  2. Nginx хост → проксирует на localhost:8082
  3. Docker Nginx → анализирует путь
     • /api/* → Backend контейнер
     • /* → Frontend контейнер
  4. Backend → обращается к PostgreSQL
  5. Ответ возвращается по цепочке обратно

═══════════════════════════════════════════════════════════════════════

РЕЖИМЫ РАБОТЫ:

  Development:  ./dev.sh up
    • Hot reload (автоперезагрузка при изменениях)
    • Vite dev server на порту 8081
    • Используется docker-compose.dev.yml

  Production:   ./prod.sh up
    • Оптимизированная сборка
    • Минифицированный код
    • Готово для корпоративной сети
    • Используется docker-compose.yml
