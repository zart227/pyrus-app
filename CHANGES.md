# Список изменений для настройки доступа через /pyrus

## Дата: 21 октября 2025

### Цель
Настройка приложения Pyrus Tasks для доступа через корпоративную сеть по адресу `http://адрес_сервера/pyrus/`

## Внесенные изменения

### 1. Frontend конфигурация

#### `frontend/vite.config.js`
- **Добавлено:** `base: '/pyrus/'`
- **Причина:** Указывает Vite, что приложение будет работать по пути `/pyrus/` вместо корневого пути

#### `frontend/src/router/index.js`
- **Изменено:** `createWebHistory('/pyrus/')` вместо `createWebHistory('/')`
- **Причина:** Vue Router должен знать базовый путь для правильной маршрутизации

### 2. Новые файлы

#### `prod.sh` ⭐
Скрипт для управления production окружением:
- `./prod.sh up` - Запуск в production режиме
- `./prod.sh down` - Остановка
- `./prod.sh logs` - Просмотр логов
- `./prod.sh ps` - Статус контейнеров
- `./prod.sh restart` - Перезапуск
- `./prod.sh rebuild` - Пересборка
- `./prod.sh dev` - Переключение на dev режим

#### `nginx-host.conf` ⭐
Конфигурация Nginx на хост-машине:
- Проксирование `/pyrus/` на `http://localhost:8082/`
- Правильные заголовки для работы приложения
- Поддержка WebSocket
- Редирект `/pyrus` → `/pyrus/`

#### `SETUP_COMMANDS.sh` ⭐
Автоматический скрипт установки:
- Установка Nginx
- Копирование и активация конфигурации
- Проверка и перезапуск Nginx

#### `QUICKSTART.md`
Краткая инструкция по быстрому запуску (3 шага)

#### `INSTALL.md`
Подробная инструкция включает:
- Пошаговую установку
- Команды управления
- Устранение неполадок
- Настройка безопасности (firewall, SSL)
- Резервное копирование
- Мониторинг

#### `CHANGES.md`
Этот файл - описание всех изменений

### 3. Неизмененные файлы

Следующие файлы уже были настроены правильно и не требуют изменений:
- `nginx.conf` - главный Nginx в Docker
- `frontend/nginx.conf` - Nginx для frontend контейнера
- `docker-compose.yml` - конфигурация Docker Compose
- `docker-compose.dev.yml` - конфигурация для dev режима

## Инструкции по развертыванию

### Вариант 1: Автоматическая установка (рекомендуется)
```bash
sudo ./SETUP_COMMANDS.sh
./prod.sh up
```

### Вариант 2: Ручная установка
См. `QUICKSTART.md` или `INSTALL.md`

## Проверка работы

После установки и запуска:

1. Проверьте статус контейнеров:
   ```bash
   ./prod.sh ps
   ```

2. Проверьте логи:
   ```bash
   ./prod.sh logs
   ```

3. Откройте в браузере:
   ```
   http://адрес_вашего_сервера/pyrus/
   ```

## Откат изменений (если нужно)

### Вернуть приложение к работе на корневом пути

1. В `frontend/vite.config.js` удалите строку `base: '/pyrus/'`
2. В `frontend/src/router/index.js` измените на `createWebHistory('/')`
3. Пересоберите: `./prod.sh rebuild`

### Удалить конфигурацию Nginx
```bash
sudo rm /etc/nginx/sites-enabled/pyrus
sudo rm /etc/nginx/sites-available/pyrus
sudo systemctl restart nginx
```

## Дополнительная информация

- Порты используемые приложением: 80, 8000, 8081, 8082, 5433
- База данных: PostgreSQL 15
- Backend: FastAPI (Python)
- Frontend: Vue 3 + Vite
- Веб-сервер: Nginx

## Поддержка

При возникновении проблем:
1. Проверьте логи: `./prod.sh logs`
2. Проверьте статус: `./prod.sh ps`
3. См. раздел "Устранение неполадок" в `INSTALL.md`
